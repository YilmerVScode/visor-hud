MARK NUBE

MARK nube es el visor de internet: funciona con el PC apagado y desde cualquier red. Este botón le copia la personalidad y la memoria de MARK. Tu clave de Gemini y tu correo no se copian.
Preparando…
Se abre en Safari. Úsalo siempre desde Safari: si lo añades a la pantalla de inicio, iOS le da una memoria aparte.
Aquí MARK funciona aunque el PC esté apagado, desde cualquier red. Puede responder, buscar en internet, mirar por la cámara y leer los datos del HUD. Sin el PC no puede controlar el ordenador.
  1. Abre aistudio.google.com/apikey, toca Crear clave de API y cópiala. Mejor una clave solo para el móvil, así puedes borrarla sin afectar a tu PC.
  2. Pégala aquí y pulsa GUARDAR. Se queda solo en este iPhone.

BATERÍA DEL IPHONE

Safari no deja leer la batería, pero un atajo del iPhone se la puede enviar a MARK.
  1. Toca COPIAR.
  2. Abre Atajos → + → añade la acción Obtener nivel de batería.
  3. Añade la acción Texto: pega la dirección y, justo al final, toca la variable Nivel de batería en la barra sobre el teclado.
  4. Añade Obtener contenido de URL. Debe decir «Obtener contenido de Texto». Pulsa ▶ para probar: verás "ok":true.
  5. Llámalo Batería a MARK.
  6. En Automatización crea: App → Safari → Se abre, y Cargador → Se conecta / Se desconecta. En cada una elige Ejecutar inmediatamente y la acción Ejecutar atajo → Batería a MARK.
Cargando…

Mantén pulsada la imagen y elige «Guardar en Fotos». Toca para cerrar.
